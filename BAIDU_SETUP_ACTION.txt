BAIDU SETUP — EXACT STEPS TO EXECUTE NOW
========================================

YOU WILL NEED:
- Chinese phone number (for SMS verification) OR email + VPN
- 15 minutes

STEP 1: CREATE BAIDU ZHANZHANG ACCOUNT
======================================

1. Go to: https://zhanzhang.baidu.com
   (If you're outside China: use VPN, set to Shanghai or Beijing)

2. Click "登录" (Sign in) or "注册" (Register)

3. If registering: use your email, verify, create password

4. Once logged in, you'll see dashboard

STEP 2: ADD YOUR SITE TO BAIDU
==============================

1. In dashboard, click "添加网站" (Add Website)

2. Enter domain: mrmallorcagolf.com

3. Select "验证方式" (Verification method):
   - Choose "HTML标签验证" (HTML Tag Verification) ← EASIEST

4. Baidu shows you a line like:
   <meta name="baidu-site-verification" content="xxxxxxxxxx" />

   COPY THE CONTENT VALUE (the "xxxxxxxxxx" part)

STEP 3: ADD META TAG TO CODE & DEPLOY
====================================

You will receive something like:
   <meta name="baidu-site-verification" content="xxxxx1234xxxxx" />

Do this:

1. Open: src/app/layout.jsx

2. Find line 50-60 area (the <Head> section with meta tags)

3. Add this line (replace xxxxx1234xxxxx with your actual code):
   <meta name="baidu-site-verification" content="xxxxx1234xxxxx" />

4. Save file

5. Run:
   npm run build
   npm run check:ready

6. If both pass, deploy:
   git add .
   git commit -m "Add Baidu site verification meta tag"
   git push origin main

   (Wait ~60 seconds for Vercel to deploy)

STEP 4: VERIFY IN BAIDU ZHANZHANG
================================

1. Go back to Baidu Zhanzhang browser tab

2. Click "验证" (Verify) button

3. Baidu will check if meta tag is live

4. If successful: ✓ Site verified
   If failed: Wait 5 minutes, try again (DNS propagation)

STEP 5: SUBMIT SITEMAP
=====================

1. In Baidu Zhanzhang dashboard, find "网站地图" (Sitemap)

2. Click "添加" (Add)

3. Enter:
   https://mrmallorcagolf.com/sitemap.xml

4. Click Submit

5. Status shows: "已提交" (Submitted) or "处理中" (Processing)

STEP 6: SET UP BAIDU TONGJI (ANALYTICS)
======================================

1. Go to: https://tongji.baidu.com/

2. Sign in with same Baidu account (or register if different)

3. Click "新增网站" (Add Website)

4. Enter domain: mrmallorcagolf.com

5. Baidu generates a tracking ID (ba_token):
   - Looks like: 1234567890 (11 digits)

   COPY THIS NUMBER

STEP 7: ADD BAIDU ANALYTICS TOKEN TO CODE
=========================================

1. Open: src/app/layout.jsx

2. Find line ~221:
   var ba_token = '';

3. Replace with (use your actual token from Baidu):
   var ba_token = '1234567890';

4. Save file

5. Run:
   npm run build
   npm run check:ready

6. If both pass, deploy:
   git add .
   git commit -m "Add Baidu Analytics token"
   git push origin main

   (Wait ~60 seconds for Vercel)

STEP 8: VERIFY BAIDU ANALYTICS IS TRACKING
==========================================

1. Open: https://mrmallorcagolf.com/zh (from China or VPN)

2. Open Chrome DevTools (F12)

3. Go to Network tab

4. Refresh page

5. Filter for "baidu" or "hm.baidu.com"

6. Should see requests to hm.baidu.com with your ba_token

7. Go to Baidu Tongji dashboard

8. You should see pageview events in real-time

If you don't see it: wait 5 minutes and refresh (takes time to show)
