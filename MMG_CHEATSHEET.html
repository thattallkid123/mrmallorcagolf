Mr Mallorca Golf — Quick Reference

Pricing changed
Update a green fee,
buggy rate, or TO discount
  1. Open Google Drive → Reference →
    MMG_COURSE_PRICING_MASTER.xlsx
    Phone: Sheets app · PC: Excel
  2. Find the course row. Edit the cell. Save.
  3. On PC — double-click the shortcut:
    MMG - Update Pricing and Deploy
Also exports the intel queue automatically.
Arabella courses (yellow rows) = 15% TO discount.
Heard something useful
Log a perk, deal, news
or content idea
  1. Open Google Drive → Reference →
    MMG_COURSE_PRICING_MASTER.xlsx
  2. Go to the Course Intel tab.
    Add a row: course · date · type · detail.
  3. On PC — double-click the shortcut:
    MMG - Update Pricing and Deploy
    (same shortcut — it does both)
Types: perk · deal · news · content
Queue saved to: Drive → Reference → COURSE_INTEL_QUEUE.md
New content
Write a blog post
or deploy the website
  1. Tell Claude your notes → review draft → approve.
  2. Open terminal in mrmallorcagolf-real:
    npm run predeploy
    Fix any errors.
  3. git add -A && git commit -m "…" && git push
    Live in ~2 min at mrmallorcagolf.com
Claude reads the brand voice + pipeline guides automatically.
For social/Chinese content — just ask Claude.
