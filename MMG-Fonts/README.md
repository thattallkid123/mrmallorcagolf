# MMG Fonts

Local source fonts for the Mr Mallorca Golf website.

The site uses `next/font/local` in `src/app/root-layout-shared.jsx` so production builds do not need to fetch Google Fonts during CI or Vercel deploys.

## Families

- Jost: 300, 400, 500 normal
- Cormorant Garamond: 400, 500, 600 normal and italic

The files were downloaded from Google Fonts on 2026-08-15 and are used under the Google Fonts open-source font licences.
