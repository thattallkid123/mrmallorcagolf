GLOBAL SEARCH IN ALL FILES
==========================

In your IDE, use Find in All Files:

FIND:  \.jpg
WHERE: src/lib/ src/app/
REPLACE: .webp

FIND:  \.jpeg
WHERE: src/lib/ src/app/
REPLACE: .webp

(Note: Be careful with .png — only change in /blog/ folders,
 not logos or other UI elements)

VERIFICATION AFTER REPLACEMENT
==============================

1. npm run check:text
2. npm run build (will error if references broken)
3. npm run dev
4. Browse to each page and check images load


ROLLBACK IF NEEDED
==================

If images don't display after changes:
1. Revert the .jsx/.js changes: git checkout src/
2. Keep the .webp files as backup
3. Re-run the search-and-replace more carefully
